# State Machines (dev.cortez.state-machines)

A lightweight, extensible set of utilities to build state machines for Unity projects.

## Installation

1. Open Unity Package Manager (Window > Package Manager).
2. Click the + button and choose "Add package from disk...".
3. Select `Packages/dev.cortez.state-machines/package.json`.

## Structure

- Runtime: Core runtime code and assemblies.
- Editor: Editor-time tooling and inspectors.
- Tests
  - Runtime: PlayMode tests.
  - Editor: EditMode tests.
- Documentation~: Package documentation entry point.
- Samples~: Importable samples via Package Manager.

## Requirements

- Unity 6000.0 or newer
- Universal Render Pipeline supported projects are fine (not required).
